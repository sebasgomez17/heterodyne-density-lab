# Scientific figure inputs

The included vector PDF figures were generated by the implemented package and
independent analytic/same-rule validation calculations. They are inputs to
main.tex, not manufacturer artwork. Ordinary run scripts never overwrite them.

| Filename | Content |
| --- | --- |
| density_profiles.pdf | Representative Gaussian-family density profiles |
| imaging_geometry.pdf | Default object/image geometry |
| measurement_chain.pdf | Exact computational pipeline diagram |
| detector_noise_budget.pdf | Default power, SNR and noise diagnostics |
| detector_linearity.pdf | Inherited approximate numerical sensitivity digitizations |
| spline_comparison.pdf | Default single-realization density/chord reconstruction |
| global_tuning.pdf | Baseline full training score surface |
| study_scale_length.pdf | Full-run density error for three representative layouts |
| study_scale_length_local_error.pdf | Full-run local scale-length error for those layouts |
| study_power_tradeoff.pdf | Baseline full power grid, three profiles, one realization |
| study_noise_contribution.pdf | Full noise/weighting comparison, selected layouts |
| study_basis_order.pdf | Full baseline order/rank/conditioning diagnostic |
| runtime_scaling.pdf | Measured C-versus-NumPy same-rule kernel times |
| quadrature_convergence.pdf | Gaussian analytic Abel convergence |

Captions in main.tex specify interpretation, sample counts, selection, and
limitations. validation_data.json retains convergence, benchmark, and baseline
tuning numbers. All study layouts/results are available by running the scripts;
manual subsets favor readable comparisons. Re-export deliberately if the code,
configuration, seeds, or physical assumptions change.
